This usecase is regarding uploading the file as request form data,reading the file as byte content from 
request through HTTP methods using multipartfile which 1 key can accepts dynamic files and generating the
response as JSON or XML message formats and persisting the byte contents and other file details into Database
and implemented exceptional handling and global handling and enabled loggers for tracing and managed commit
and rollback transaction.

Implemented in various file extensions - .txt, .csv, .jpeg/jpg/png, .pdf, .xlsx, .json, .xml
